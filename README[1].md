# Site vitrine EcoResearch

Ce dossier contient un site vitrine professionnel en français pour l’Association EcoResearch.

## Fichiers
- index.html : structure du site
- style.css : design responsive
- script.js : menu mobile, animation, formulaire mailto

## Mise en ligne rapide
1. Ouvrir index.html dans un navigateur pour vérifier le rendu.
2. Modifier les informations de contact dans index.html.
3. Remplacer contact@ecoresearch.org par l’adresse officielle.
4. Déposer les trois fichiers sur un hébergement web ou GitHub Pages.

## Sections incluses
Accueil, À propos, Recherche, Publications, Études et consultations, Événements, Formations, Actualités, Contact.
